# Roda: Your Premium Learning Hub

Create a modern, lightweight Persian RTL educational website called "Roda".

The website is for selling educational packages and publishing educational articles about admin skills, digital skills, content management and educational topics.

The main goal of this website:

- Professional online presence

- Getting required business approvals

- Showing educational packages

- Publishing articles

Important:

This is NOT a heavy ecommerce website.

Do not create unnecessary complex features.

Keep the website fast, lightweight and easy to manage.

Do NOT add:

- User reviews

- Ratings

- Comments

- Location

- Address

- Maps

- Unnecessary sections

Brand:

Name:

رودا

Subtitle:

دایرکتوری و سناریو

========================

DESIGN SYSTEM

========================

Create a premium modern educational design.

Style:

- Minimal

- Clean

- Professional

- Modern

- Lightweight

- High quality UI

Colors:

- Main background: white

- Brand color: purple

- Light purple accents

- Dark purple typography

The website should feel like a premium educational platform, not a blog and not a complicated online store.

Use:

- Modern typography

- Smooth animations

- Clean spacing

- Professional cards

========================

HEADER / HERO SECTION

========================

Create a beautiful header visible across the website.

Requirements:

- Light purple header background

- Large Persian title:

رودا

- Smaller subtitle below:

دایرکتوری و سناریو

- Add a temporary image placeholder instead of a logo.

- The image should be easy to replace later with the official logo.

Do not add any address or location.

========================

REACT BITS SCANNER EFFECT

========================

Integrate the React Bits <Scanner /> component in the hero/header section.

Use the real WebGL Scanner effect with ogl dependency.

The effect must be:

- Only used in the top hero/header area

- A background visual effect

- Elegant and subtle

- Not distracting

- Optimized for performance

Configuration:

color1:

#6e4df2

color2:

#ff27f8

color3:

#FFFFFF

speed:

0.35

sweepSpeed:

0.2

sweepWidth:

1.8

glow:

0.18

scanDirection:

vertical

brightness:

0.8

contrast:

1.1

opacity:

0.35

mouseInteraction:

true

The Scanner should create a premium futuristic educational feeling.

========================

PAGES

========================

Create these pages:

1. Home page

Sections:

- Hero section

- Introduction about Roda

- Educational packages preview

- Latest articles preview

- Simple contact section

2. About Roda

A simple page introducing the brand and creator.

3. Educational Packages

Create a lightweight product section.

Each product should have:

- Product image

- Product title

- Description

- Price field

- Purchase button placeholder

Important:

No payment gateway is required.

The product system should only allow displaying and managing products.

4. User Registration / Login

Create a simple authentication system.

Users can:

- Register

- Login

- Access profile

Keep it simple and lightweight.

5. Articles System

Create a complete article/blog system.

The website owner should be able to publish articles about:

- Admin skills

- Social media management

- Digital marketing

- Content creation

- Educational topics

Article features:

- Article title

- Cover image

- Category

- Rich text content

- Add images inside articles

- Related articles section at the bottom

At the end of every article display:

"موضوعات مشابه"

and show links to related articles.

6. Contact page

Only create a contact form.

Do not add:

- Address

- Map

- Location

7. Rules page

8. Privacy Policy page

========================

ADMIN MANAGEMENT

========================

The website owner must have full control.

Create an easy management system.

Admin should be able to:

- Add new articles

- Edit articles

- Delete articles

- Upload article images

- Add new educational packages

- Edit product information

- Manage website content

- Change temporary logo image later

- Update pages easily

The management system must be simple enough for a non-programmer user.

========================

PERFORMANCE REQUIREMENTS

========================

Very important:

The website must be lightweight.

Requirements:

- Fast loading speed

- Optimized images

- Lazy loading for heavy components

- Lazy load Scanner WebGL effect

- Disable heavy animations on low-power devices

- Mobile optimized

- Responsive on:

  - Mobile

  - Tablet

  - Desktop

Avoid unnecessary libraries.

Keep hosting requirements low.

The final website should run smoothly on affordable hosting.

========================

TECHNICAL REQUIREMENTS

========================

Use:

- React

- Tailwind CSS

- Modern component structure

- Persian RTL support

- Clean reusable components

Make the code easy to maintain and expand later.

FINAL RESULT:

Create a lightweight but visually impressive educational website.

The feeling should be:

"A modern official educational brand website with premium design, articles and simple educational package management."

Not a heavy ecommerce website.

Not a simple blog.

A professional lightweight educational platform.
